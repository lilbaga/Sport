Адаптивная типографика HandsUp

Размер шрифта меняется вместе с шириной экрана: на телефоне компактно, на планшете крупнее, на десктопе максимально комфортно для чтения.

Почему размер шрифта должен меняться

На узком экране длинные строки крупного текста занимают слишком много места, а на большом мониторе мелкий текст быстро утомляет глаза. Media queries позволяют задать свои размеры для каждого диапазона ширины.

Как это устроено в этой странице

Базовые стили написаны для мобильных устройств. Запрос min-width: 576px увеличивает шрифты для планшетов, а min-width: 992px — для десктопов. Значок вверху страницы показывает, какой диапазон сейчас активен.
